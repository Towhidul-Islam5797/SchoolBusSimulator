================================================================
SPRINT GOAL
================================================================
One traffic light cycles Green -> Yellow -> Red -> Green on its own.
Only the active lamp glows and only its Point Light is on.

================================================================
DECISIONS
================================================================
- Cycle: US style, Green -> Yellow -> Red. No Red+Yellow phase.
  Confirmed by Rahat.
- Default timings: green 10 s, yellow 3 s, red 10 s. All tunable in
  the Inspector. Not yet confirmed with stryflex.
- Each traffic light runs on its own. startState lets two lights at
  one junction start out of step. No automatic sync.

================================================================
CHANGES
================================================================
New: Assets/V1.0/Scripts/Signs/TrafficLightController.cs
  - LightState enum: Green, Yellow, Red
  - Start(): applies startState
  - Update(): timer moves to the next state when the current
    state's duration passes
  - SetLamps(): on material + Point Light for the active lamp,
    off material + Point Light off for the other two

================================================================
EDITOR STEPS (done by Claude on Rahat's request, steps 1 to 4)
================================================================
TrafficLampOff.mat was created next to the other lamp materials in
Materials/Lights. Step 5 was not done.

1. Create material TrafficLampOff (URP Lit, dark grey, emission off).
2. Rename GreenLIght 1.mat to YellowLight.mat in the Project window.
3. Add TrafficLightController to the root of TrafficLight.prefab.
4. Wire fields:
     Lamps         Red_Light, Yellow_Light, Green_Light
     Point Lights  the Point Light child of each lamp
     Materials     RedLIght, YellowLight, GreenLIght, TrafficLampOff
5. Optional: remove the 3 SphereColliders on the lamps.

SPRINT 1b - LOD GROUP + POINT LIGHT LOD (added on Rahat's request)
================================================================
Note: LOD is optimization work, normally Stage 4. Added early at
Rahat's request.

Prefab: LOD Group on the TrafficLight root.
  LOD 0   100% to 20%   pole + lamps, Point Lights on
  LOD 1   20% to 3%     pole + lamps, Point Lights off
  Culled  below 3%      everything hidden

Script: TrafficLightController.cs, new region Sprint 1b.
  - New field lodGroup (wired in the prefab).
  - UpdatePointLightLOD(): each frame works out the traffic light's
    screen height with the same maths as the LOD Group. Point Lights
    are allowed only while it is in LOD 0.
  - SetLamps(): Point Lights now also require pointLightsAllowed.

Editor steps (Rahat):
  1. Open the prefab, select the root, find the LOD Group.
  2. Drag the root TrafficLight (the pole mesh) into LOD 0 and LOD 1.
     Claude could not find the pole renderer's ID from outside Unity.
  3. Press Recalculate Bounds. Save the prefab.

Done condition: in Play mode, moving away from a light turns its
Point Light off at the 20% divider while the lamp colour still
shows. Moving farther (below 3%) hides the whole traffic light.

================================================================
SPRINT 1c - LAMPS HIDE INSTEAD OF SWAPPING MATERIAL
================================================================
The traffic light model has its own dark tinted lenses behind the
lamp spheres. Hiding a sphere shows that lens, which looks like a
real unlit traffic light.

Changes:
  - SetLamps(): turns each lamp's Mesh Renderer on/off instead of
    swapping materials. Point Lights are still handled separately.
  - Removed fields redOnMaterial, yellowOnMaterial, greenOnMaterial,
    lampOffMaterial.
  - Deleted TrafficLampOff.mat (no longer used).
  - Fixed compile error: the C# API name is
    LOD.screenRelativeTransitionHeight (screenRelativeHeight is only
    the name inside the prefab file).

Exception to the on/off material pair rule: the model provides the
"off" look itself, so no off material is needed.

Done condition: in Play mode only the active lamp's glowing sphere
shows, the other two show the model's dark tinted lenses.
