================================================================
BUS CONTROLLER - KEY CHANGES
================================================================
- Removed all hardcoded WheelCollider physics overrides from code.
  Suspension, friction, center of mass, angular damping are now
  controlled entirely from the Inspector.

- Fixed motor torque sign for D and R gears (was inverted, caused
  wrong-direction movement).

- Added zero-then-set pattern for motorTorque before applying brake,
  to stop wheels fighting each other and spinning visually.

- Added smooth throttle ramping (Mathf.MoveTowards) instead of
  instant on/off. Controlled by accelerationSensitivity.

- Added separate steering speed and steering return speed.
  Wheels turn faster than they return to center (lazy self-center,
  feels like a heavy bus).

- Added speed-based steering reduction. Max steer angle drops from
  maxSteerAngle (low speed) to minSteerAngleAtSpeed (high speed),
  blended by steeringReductionSpeed.

- Added maxSpeed with torque falloff. Motor force scales down to
  zero as currentSpeed approaches maxSpeed. Bus accelerates hard
  from standstill, struggles near top speed.

- Fixed rolling resistance snapping bus to 0 instantly at low speed.
  WheelCollider locks even with tiny brake torque at very low speed.
  Fix: below 2 MPH, rolling resistance brake = 0. Physics engine
  handles the final crawl-to-stop naturally.

- currentSpeed clamped to 0 if below 0.01 to avoid floating point
  noise (e.g. 1.3e-08) showing in Inspector.

- currentSteer changed to [HideInInspector] public so
  SteeringWheelRotator can read it.

================================================================
CAMERA FOLLOW - KEY CHANGES
================================================================
- Rewritten to follow BusRoot directly (no rear axle pivot needed).
- Position: fixed offset from BusRoot, recalculated every frame
  using Quaternion rotation - NO SmoothDamp, NO lag. Camera stays
  at exact distance set in editor.
- Y rotation: maintains the original offset between camera's
  starting Y rotation and bus's Y rotation (yRotationOffset).
  Whatever angle you place the camera at in the editor is
  preserved as the bus turns.
- X rotation: fixed value (cameraXRotation), inspector-editable,
  does not change with bus pitch.
- FOV and rotation damping still scale with speed
  (lowSpeedFOV/highSpeedFOV, lowSpeedRotationDamping/
  highSpeedRotationDamping).

Setup required in Inspector (Main Camera):
  Bus Transform: BusRoot
  Camera X Rotation: 20 (adjust to taste)
