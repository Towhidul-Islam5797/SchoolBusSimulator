================================================================
SPRINT GOAL
================================================================
Far-away traffic lights cost less. Point Lights turn off at medium
distance, and the whole traffic light is hidden when it is tiny on
screen.

================================================================
CHANGES
================================================================
Prefab: LOD Group on the TrafficLight root.
  LOD 0   100% to 20%   pole + lamps, Point Lights on
  LOD 1   20% to 3%     pole + lamps, Point Lights off
  Culled  below 3%      everything hidden

Script: TrafficLightController.cs, region "Sprint 1b - Point Light LOD"
  - A LOD Group can only hide meshes, not Lights, so the script
    does that part.
  - New field lodGroup (wired in the prefab).
  - UpdatePointLightLOD(): each frame works out how tall the traffic
    light is on screen, with the same maths as the LOD Group. Point
    Lights are allowed only while it is in LOD 0.
  - GetScreenHeight(): object size / camera view height at that
    distance, times QualitySettings.lodBias.
  - Start() reads the 20% line from the LOD Group once.

Fix: the C# name is LOD.screenRelativeTransitionHeight.
screenRelativeHeight is only the name inside the prefab file. The
compile error made Unity drop the lodGroup wiring on every save.
